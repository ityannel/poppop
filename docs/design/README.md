## 決める前の共通の物差し

PopCorn の根幹は、次の 5 つです。新しい機能は、これを崩さないものだけを入れます。

1. **左から右の流れと非破壊**：値は `>>` で流れ、元の値を書き換えない。
2. **厳格さ**：`Bool` の暗黙の変換をしない。エラーには分類がある。
3. **評価の順序の約束**：式とパイプラインは、左から右、必要になった時点で評価する。外部効果（表示、待つ、通信、ファイル）も、その順に起きる。
4. **単一ファイル完結**：モジュール分割や、第一級関数を入れない。
5. **初心者の読みやすさ**：書き方が少なく、エラーが、直し方を教えてくれる。

## 決めるときの手順

1. 実際の困りごとを、サンプルやレッスンの形で、書き出す。
2. いまの PopCorn だけで書けるか、確かめる（書けるなら、書き方の例を仕様書に載せて終わり）。
3. 足すなら、物差しの 5 つに照らして、崩れる点を、書き出す。
4. 仕様書、実装、サンプル、レッスン、整形、色付け、VS Code 拡張、テストを、同じコミットで揃える。
