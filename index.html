PopCorn 1実験中のアルファ版

書いた順に、動く。

PopCorn（ポップコーン）は、値を >> で、左から右へつないでいく、小さなプログラミング言語。読んだ順に、何が起きるかがわかります。

ブラウザで試す さわって遊ぶ
  • インストールなしで動く
  • エラーは日本語
  • テストも書ける

粒をタップすると、ポップします

01きまりさわり方：タップ

覚えることは、
3つだけ。

PopCorn の文は、まるで文章のよう。左から読んで、. で終わります。

02読みやすささわり方：タップ

読む順が、
そのまま動く順。

「偶数だけ選んで、2 倍して、合計する」。同じことを、2 つの書き方でくらべてみましょう。

入れ子の書き方（Python の例）

いちばん内側の nums から、外へ外へ。目は右から左へ、行ったり来たりします。

PopCorn（書いた順に）

書いた順に、左から右へ。目は、まっすぐ進むだけ。

    05道具さわり方：タップ入力
    
          
    ちょっと便利な記号と、
    やさしいエラー。
    
          
    流れを止めずに、のぞいたり、守ったり、分けたり。まちがえたときは、日本語で教えてくれます。
    
        
    
        
    
          
    
            
            
            
            
            
          
    

          
    
            
    
              
    流れの途中を、のぞく
    
              
    >> を >?> にすると、そこを通る値が表示されます。値は変わりません。コードの >> をタップしてみよう。
    
              
    表示の line 1 after Range は「1 行目の Range のあと」、(List) は値の種類です。
    
            
    
            
    
              
    
              
    
            
    
          
    

          
    
            
    
              
    失敗したら、差し替える
    
              
    >!> より左でエラーが起きたら、右の値に差し替えて、そのまま進みます。数にできない文字を入れてみよう。
    
            
    
            
    
              
              
    
              
    
              
    
            
    
          
    

          
    
            
    
              
    ひとつの値から、いくつも計算する
    
              
    Fork は、同じ値を、いくつもの道に分けて計算します。数字を変えてみよう。
    
            
    
            
    
              
    
              
    
              
    
            
    
          
    

          
    
            
    
              
    テストも、PopCorn で書ける
    
              
    名前が Test で始まる関数がテストです。popcorn test で動かすと、ちがうところを日本語で教えてくれます。
    
              
            
    
            
    
              
    
              
    
            
    
          
    

          
    
            
    
              
    まちがえても、日本語で
    
              
    どこが、なぜダメなのかを、日本語で伝えます。よくあるまちがいを、わざとしてみよう。
